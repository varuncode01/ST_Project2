<h2>📌 About the Project</h2>
<p>
This project uses machine learning models to predict GPU kernel runtime performance
based on configurations like work-group sizes, vector widths, and stride parameters.
It leverages classification and regression techniques to analyze performance behavior
and optimize kernel execution.
</p>

<h2>🎯 Objective</h2>
<p>
The objective is to accurately predict the <b>Average Run Time Category</b> of GPU kernels,
enabling efficient scheduling, resource optimization, and hardware-software co-design.
</p>

<h2>📊 Machine Learning Models Used</h2>
<ul>
  <li>Logistic Regression (Multinomial)</li>
  <li>Random Forest Classifier</li>
  <li>K-Nearest Neighbors (KNN)</li>
</ul>
<p>
Each model is evaluated using standard metrics such as Accuracy, Precision, Recall, F1-score,
and visualized with confusion matrices and classification reports.
</p>
